# Testing:

Compile with tikz support.
```
npx quartz build --serve
```

Compile without tikz support.
```
SKIP_TIKZ=1 npx quartz build --serve
```

Compile without custom OG Images.
```
SKIP_OG_IMAGE=1 npx quartz build --serve
```

Compile without Desmos SVGs.
```
SKIP_DESMOS=1 npx quartz build --serve
```

Test OG Images.
```
npx tsx quartz/scripts/og-debug.tsx notes/<TOP LEVEL FOLDER>/title
```

git submodule update --init --recursive --remote --force

# Desmos Support

This repository includes custom plugins to support [obsidian-desmos](https://github.com/Nigecat/obsidian-desmos) graphs.

**1. Desmos Transformer (`quartz/plugins/transformers/desmos.ts`)**
- Scans markdown for `desmos-graph` code blocks.
- Parses the block content (equations, settings) exactly like the Obsidian plugin.
- **Renders the graph to an SVG** using a headless browser (Playwright/Chromium).
- Replaces the code block with an image tag pointing to the generated SVG in `static/desmos/`.
- Use the `SKIP_DESMOS=1` environment variable to skip this process during builds.

**2. Desmos Emitter (`quartz/plugins/emitters/desmos.ts`)**
- Copies any pre-existing SVGs from `content/notes/.desmos/` to the public output folder at `notes/desmos/`.
- This provides a fallback or compatibility for graphs already generated by Obsidian.

*Note: Generating Desmos SVGs requires Chromium to be installed on the system.*
